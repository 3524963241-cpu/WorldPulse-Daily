## 二、一条数据长什么样

```json
{
  "id": "46ee43f3cce0",
  "title": "在军事基地发生致命事件后，艾伯塔省发生重大火灾",
  "summary": "加拿大国防部长周六表示，在阿尔伯塔省的一个军事基地发生的事件造成了重大火灾，造成人员伤亡。",
  "category": "geopolitics",
  "country": "加拿大",
  "lat": 56.13,
  "lng": -106.35,
  "published_at": "2026-10-18T07:56:08Z",
  "source": "NPR World",
  "url": "https://www.npr.org/2026/10/18/nx-s1-6007276/fire-alberta-deadly-canada-military-base",
  "heat": 91
}
```

> `id` 是 **12 位十六进制**，由原文 URL 算哈希得来。同一条新闻永远是同一个 id，
> 所以换一期数据后，你仍然能认出"这条我昨天见过"。

完整字段说明见 `docs/前端对接说明.md`。

## 二·B、除了 news.json，还有两份数据可以直接用

| 文件 | 内容 | 谁需要 |
|---|---|---|
| `data/digest.json` | **今日概览**：最热三条 + 三个领域各一句中文小结 | 想做"每日摘要"模块的话直接用，不用自己写文案 |
| `data/archive/index.json` | **历史索引**：`{"dates": [{date, count, has_digest}]}`，最新在前 | 想做"历史回看"的话，先读它拿日期列表 |

`digest.json` 里最有用的是 `sections`，每项是一句完整的中文：

```json
{"category": "geopolitics", "count": 5,
 "text": "地缘冲突 5 条，最受关注的是《阿尔伯塔省军事基地发生致命事件后爆发大火》（热度 91），来自 NPR World。其余报道来自 CNBC World News。"}
```

可以直接当一句话渲染。注意 **`text` 可能是空字符串**（某领域当天 0 条），遇到就跳过不渲染。

## 四、容易踩的坑

- **`lat` / `lng` 为 `null`** 的条目（当前 20 条中有 4 条）**不能上地图**，只能在列表显示
- **`summary` 可能是空字符串**，渲染时要兜底（`item.summary \|\| ''`）
- 数组**已按 `heat` 从高到低排序**，前端不用再排
- 条数**固定 20 条**（后端配额：地缘 5 / 政治 7 / 市场 8），但别写死，用 `data.news.length`
- 标题若以 `[EN]` 开头，说明翻译接口当天额度用尽，回退成了英文原文
- **不要用数组下标当 id**，用 `item.id` 字段（`news-001` 那种序号已经废弃）
